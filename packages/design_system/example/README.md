# design_system_example

Galería de `design_system`: muestra cada componente, con selectores de idioma, tema (claro u oscuro) y escala de texto para revisar cómo se adaptan.

Como cualquier consumidor de los paquetes, inyecta todos los textos desde `assets/i18n/` al arrancar (`injectTranslations` de `core_ui`).

```sh
flutter run
flutter test
```
